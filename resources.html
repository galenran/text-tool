文本编辑器推荐

💻

Visual Studio Code

微软开发的免费开源代码编辑器，支持几乎所有编程语言，拥有丰富的插件生态。是目前最受欢迎的代码编辑器之一。

免费 开源 跨平台
访问官网 →
📝

Sublime Text

轻量级但功能强大的文本编辑器，启动速度极快，界面简洁优雅。特别适合快速编辑和大文件处理。

付费 跨平台 高性能
访问官网 →
📄

Typora

专为 Markdown 设计的所见即所得编辑器，界面简洁美观，写作体验极佳。支持导出为 PDF、HTML 等多种格式。

付费 跨平台 Markdown
访问官网 →
🧠

Obsidian

基于 Markdown 的知识管理工具，支持双向链接、图谱视图。适合构建个人知识库和第二大脑。

免费 跨平台 知识管理
访问官网 →
📋

Notepad++

Windows 平台经典的文本编辑器，小巧轻便，功能丰富。特别适合查看日志和快速编辑文本。

免费 开源 Windows
访问官网 →
🎨

Atom

GitHub 开发的开源文本编辑器，高度可定制，界面美观。虽然性能不如 VS Code，但插件生态丰富。

免费 开源 跨平台
访问官网 →
